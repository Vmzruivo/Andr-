# Codex Vitae — Social

A camada social do Codex Vitae foi preparada com um modelo de dados para:

- perfis públicos;
- publicações de progresso e conquistas;
- curtidas e comentários;
- amizades/solicitações;
- conversas privadas;
- mensagens com controle de participantes.

## Próxima integração

O frontend deve conectar essas entidades a um backend/autenticação real. O `codex-vitae.jsx` atualmente contém a interface e o modelo `codex-vitae-social-schema.json` documenta os dados necessários.

Não são usadas credenciais ou chaves secretas no frontend.
